# SSEM — Shree Shyam Earthmovers LLP

> **Dedicated Transport & Fleet Operations**  
> Moving Cargo. Building Connectivity.

Official website and digital operations portal for **Shree Shyam Earthmovers LLP (SSEM)**, an Indian heavy transport and commercial truck fleet logistics company specializing in road construction material haulage, highway project supply lines, low-bed heavy plant mobilization, and long-haul freight.

- **Website**: [https://ssem.in](https://ssem.in)
- **Contact Desk**: [info@ssem.in](mailto:info@ssem.in)
- **Operating Headquarters**: 129, New Bus Stand Mau, District Bhind, 477222, Madhya Pradesh

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Vanilla CSS (Variables, Flexbox, CSS Grid) + Lenis smooth-scrolling
- **Icons**: `lucide-react`
- **Linting**: `oxlint`
- **Responsive layout**: Dedicated mobile experience layer while preserving the existing desktop design

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/PRADHUMAN-SINGH-1/ssem.git
cd ssem

# Install dependencies
npm install

# Start local dev server
npm run dev
```

The application will be running locally at `http://localhost:5173/`.

### Production Build

```bash
# Typecheck and build production bundle
npm run build

# Preview production build locally
npm run preview
```
